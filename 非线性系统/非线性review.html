一、简叙一般切换控制与滑模控制的不同之处，以及滑模控制的优缺点。

解答：
一般切换控制（switched control）是指根据系统状态、时间或事件逻辑在多个预先设计的子控制器（或子系统）之间进行切换的控制策略，切换可以是有限次数的、周期性的或基于平均驻留时间的，不一定存在连续的滑动模态。

滑模控制（sliding mode control）是切换控制的一种特殊形式，它通过预先设计一个滑动面（sliding surface，通常为 s(x)=0s(x) = 0s(x)=0），使得系统状态在有限时间内到达滑动面，并通过高频切换控制律迫使状态沿滑动面做“滑动运动”（sliding mode），从而实现降阶动态。

不同之处：

  • 切换逻辑不同：一般切换控制不强制状态必须停留在特定流形上，而滑模控制的核心是强制状态在滑动面上运动。
  • 鲁棒性设计侧重点不同：滑模控制利用等效控制和切换项专门抵消匹配不确定性；一般切换控制更侧重于切换稳定性分析（如多Lyapunov函数、平均驻留时间）。

滑模控制的优点：

  • 对匹配参数不确定性和外部扰动具有完全鲁棒性（invariance）。
  • 动态响应快、易于工程实现。
  • 设计简单（仅需界信息）。

滑模控制的缺点：

  • 高频切换导致控制信号抖振（chattering），可能激发未建模高频动态或损坏执行器。
  • 需要已知不确定性的上界。
  • 对非匹配扰动鲁棒性较差。

一、简叙一般切换控制与滑模控制的不同之处，以及滑模控制的优缺点。

解答（超详细版）：

首先，我们先搞清楚两个概念到底是什么。

一般切换控制（switched control）：
想象你有一个很复杂的系统，你准备了好几个不同的“控制器”（比如控制器A、控制器B、控制器C）。
你会根据当前系统的状态（比如温度太高就切换到控制器A，速度太快就切换到控制器B），或者根据时间（每隔5秒切换一次），或者根据某个事件，来切换使用哪一个控制器。
切换可以是有限次（只换几次就结束了），也可以是周期性的（一直来回切换），也可以根据“平均驻留时间”（平均每次停留在某个控制器上的时间不能太短）来保证稳定。
最重要的是：它不要求系统状态必须永远停留在某一条特定的“线”或“面”上，只是不断换控制器而已。

滑模控制（sliding mode control）：
它是切换控制的一种特殊形式。
我们先人为设计一条滑动面（通常写成 s(x)=0s(x) = 0s(x)=0，比如 s(x)=x2+cx1=0s(x) = x_2 + c x_1 = 0s(x)=x2​+cx1​=0）。
控制目标是：

  1. 在有限时间内，把系统状态“拉”到这条滑动面上（s(x)=0s(x) = 0s(x)=0）。
  2. 一旦到达，就用高频快速切换的控制律（控制信号像锯齿一样疯狂抖动），强行让状态沿着这条滑动面滑动（叫做“滑动模态”）。
    这样，系统的动态就从原来的高维（比如3维）变成了低维（比如2维），相当于“降阶”了。

两者到底哪里不一样？（核心不同之处）

  • 切换逻辑完全不同：
    一般切换控制只是“换控制器”，状态可以到处跑，只要整体稳定就行。
    滑模控制必须把状态“锁死”在滑动面上运动，不允许离开！
  • 鲁棒性（抗干扰能力）设计的侧重点不同：
    滑模控制专门设计了一个“切换项”，利用等效控制 + 切换控制，可以完全抵消系统中“匹配”的参数不确定性和外部扰动（这就是著名的“不变性”）。
    一般切换控制更关心“切换会不会导致系统不稳定”，所以要用多Lyapunov函数、平均驻留时间等数学工具来证明稳定性。

滑模控制的优点（为什么很多人爱用）：

  • 超级强的鲁棒性：只要不确定性和扰动是“匹配”的（出现在控制输入通道上），控制效果就完全不受影响（不变性）。
  • 动态响应快：一旦进入滑动面，响应速度像“滑”一样快。
  • 工程实现简单：设计时你只需要知道不确定性的上界（比如扰动最大是多少），不需要精确模型。

滑模控制的缺点（实际工程里最头疼的问题）：

  • 抖振（chattering）：高频切换会导致控制信号（比如电机电压）疯狂抖动，像锯齿波一样。
    这可能会激发系统中未建模的高频动态（比如机械结构的振动），甚至损坏执行器（电机烧掉、执行器磨损）。
  • 需要知道不确定性的上界：如果你不知道扰动最大是多少，就设计不出来。
  • 对非匹配扰动鲁棒性差：如果扰动不在控制输入通道上（非匹配），滑模控制就没那么厉害了。

二、简叙相对阶的概念及其物理意义。（15 分）

解答（超详细版）：

我们考虑一个一般的非线性系统（单输入单输出）：

x˙=f(x)+g(x)u,y=h(x)\dot{x} = f(x) + g(x)u, \quad y = h(x) x˙=f(x)+g(x)u,y=h(x)

LgLfkh(x)=0,k=0,1,…,r−2L_g L_f^{k} h(x) = 0, \quad k = 0, 1, \dots, r-2 Lg​Lfk​h(x)=0,k=0,1,…,r−2

LgLfr−1h(x)≠0L_g L_f^{r-1} h(x) \neq 0 Lg​Lfr−1​h(x)=0

这些符号到底是什么意思？

  • LgLfkh(x)L_g L_f^{k} h(x)Lg​Lfk​h(x)就是先对 hhh沿着 fff求 kkk次导，再沿着 ggg求一次导。
    简单说：它告诉你输入 uuu第一次出现在输出 yyy的第几阶导数里。

物理意义（最容易懂的解释）：
相对阶 rrr代表输入 uuu到输出 yyy之间隔了多少个“积分器”（或者说“动态延迟”）。

举个最直观的例子：

  • 机械系统里，yyy= 位置，uuu= 力。
    力 → 加速度（1阶导）→ 速度（2阶导）→ 位置（3阶导）。
    所以输入 uuu第一次出现在 yyy的第2阶导数里 → 相对阶 r=2r = 2r=2。

再比如：

  • 如果 yyy是速度，uuu是力 → 相对阶 r=1r = 1r=1。
  • 线性系统里，相对阶就是传递函数分子分母阶数之差。

为什么重要？
相对阶是做反馈线性化（把非线性系统变成线性系统）的关键！
只有知道相对阶，我们才能设计坐标变换，把原系统变成“Brunovsky 标准型”（一串积分器链），然后就可以用线性控制方法来设计控制器了。
