题目 1

请从不确定性出发，对 H∞H_{\infty}H∞​ 控制以及 μ\muμ 分析和 μ\muμ 综合进行一个系统性的介绍。 需要涉及如下概念： 模型不确定性，扰动不确定性，结构不确定性，非结构不确定性，鲁棒镇定问题，鲁棒性能问题，H∞H_{\infty}H∞​ 控制，μ\muμ 分析和 μ\muμ 综合。

答案：

不确定性是鲁棒控制理论的核心出发点。实际控制系统中，名义模型（nominal model）与真实系统之间存在差异，这种差异称为不确定性（uncertainty）。不确定性可分为以下几类：

  • 模型不确定性（model uncertainty）：指系统动态特性与名义模型的偏差，包括参数不确定性（parametric uncertainty，如质量、刚度等参数在一定范围内变化）和未建模动态（unmodeled dynamics，如高频寄生效应）。
  • 扰动不确定性（disturbance uncertainty）：外部输入（如噪声、风扰、路面不平度）的幅度和频率特性未知，但通常假设其能量有界（L2L_2L2​ 范数有界）。
  • 结构不确定性（structured uncertainty）：不确定性以特定块对角形式出现（如参数块或重复标量块），反映实际物理结构（如多变量系统中各通道独立不确定）。
  • 非结构不确定性（unstructured uncertainty）：不确定性以全块形式出现，无结构约束，通常用 H∞H_{\infty}H∞​ 范数界描述（如加性不确定 Δa\Delta_aΔa​ 或乘性不确定 Δm\Delta_mΔm​，满足 ∥Δ∥∞<1\|\Delta\|_{\infty} < 1∥Δ∥∞​<1）。

这些不确定性导致闭环系统面临两大核心问题：

  • 鲁棒镇定问题（robust stabilization problem）：要求闭环系统在所有允许的不确定性 Δ\DeltaΔ（属于某个有界集）下均保持内部稳定。
  • 鲁棒性能问题（robust performance problem）：在保证鲁棒稳定的同时，满足性能规范（如跟踪误差、扰动抑制等），通常用 H∞H_{\infty}H∞​ 范数 ∥Tzw∥∞<γ\|T_{zw}\|_{\infty} < \gamma∥Tzw​∥∞​<γ 来量化，其中 www 为外部输入（扰动+参考），zzz 为评价输出（误差）。

H∞H_{\infty}H∞​ 控制正是针对上述问题而设计的。它将控制问题转化为最小化广义对象 PPP 从 www 到 zzz 的闭环传递函数 Tzw=Fl(P,K)T_{zw} = \mathcal{F}_l(P, K)Tzw​=Fl​(P,K) 的 H∞H_{\infty}H∞​ 范数：

inf⁡K∥Fl(P,K)∥∞<γ\inf_K \| \mathcal{F}_l(P, K) \|_{\infty} < \gamma Kinf​∥Fl​(P,K)∥∞​<γ

其中 KKK 为控制器。H∞H_{\infty}H∞​ 控制对非结构不确定性特别有效，能同时实现鲁棒镇定与鲁棒性能（通过小增益定理保证 ∥M∥∞<1\|M\|_{\infty} < 1∥M∥∞​<1 时对 ∥Δ∥∞<1\|\Delta\|_{\infty} < 1∥Δ∥∞​<1 的鲁棒性）。其优点是可处理多目标（如灵敏度、补灵敏度），但对结构不确定性保守性较大。

μ\muμ 分析（structured singular value analysis）则专门针对结构不确定性。结构奇异值 μΔ(M)\mu_{\Delta}(M)μΔ​(M) 定义为：

μΔ(M)=1min⁡{σˉ(Δ):det⁡(I−MΔ)=0,Δ∈Δ}\mu_{\Delta}(M) = \frac{1}{\min \{ \bar{\sigma}(\Delta) : \det(I - M\Delta) = 0, \Delta \in \boldsymbol{\Delta} \}} μΔ​(M)=min{σˉ(Δ):det(I−MΔ)=0,Δ∈Δ}1​

鲁棒镇定充要条件为 sup⁡ωμΔ(M(jω))<1\sup_{\omega} \mu_{\Delta}(M(j\omega)) < 1supω​μΔ​(M(jω))<1。μ\muμ 分析比纯 H∞H_{\infty}H∞​ 更精确，能处理结构化的 Δ\DeltaΔ（如 Δ=diag(Δ1,…,Δn)\Delta = \text{diag}(\Delta_1, \dots, \Delta_n)Δ=diag(Δ1​,…,Δn​)），避免 H∞H_{\infty}H∞​ 的保守性。

μ\muμ 综合（μ\muμ synthesis）是设计控制器 KKK 使闭环 μ\muμ 最小化的过程：

inf⁡Ksup⁡ωμΔ(Fl(P,K)(jω))<1\inf_K \sup_{\omega} \mu_{\Delta}(\mathcal{F}_l(P, K)(j\omega)) < 1 Kinf​ωsup​μΔ​(Fl​(P,K)(jω))<1

常用 D-K 迭代法：交替进行 μ\muμ 分析（求 DDD-标度）和 H∞H_{\infty}H∞​ 综合，直到收敛。该方法结合了 H∞H_{\infty}H∞​ 的数值可解性和 μ\muμ 对结构的精确性，是现代鲁棒控制的实用工具。

综上，从不确定性建模（M−ΔM-\DeltaM−Δ 结构）出发，H∞H_{\infty}H∞​ 控制提供非结构鲁棒框架，μ\muμ 分析/综合则精细化结构不确定性的处理，实现从分析到综合的完整鲁棒控制体系。

题目 4

谈谈奈奎斯特稳定性判据、小增益定理与鲁棒控制的关系。

答案：

奈奎斯特稳定性判据（Nyquist stability criterion）是经典频率域方法：对于名义开环 L(s)L(s)L(s)，闭环稳定 iff Nyquist 曲线不包围临界点 −1+j0-1 + j0−1+j0（且计及右半平面极点数）。它给出名义稳定性的充分必要条件。

小增益定理（small gain theorem）是鲁棒控制的基石：对于互联系统 M−ΔM-\DeltaM−Δ（Δ\DeltaΔ 为不确定性），若 ∥M∥∞∥Δ∥∞<1\|M\|_{\infty} \|\Delta\|_{\infty} < 1∥M∥∞​∥Δ∥∞​<1，则闭环内部稳定（对 L2L_2L2​ 信号）。它是充分条件，特别适用于非结构不确定性（Δ\DeltaΔ 无结构约束）。

三者关系：

  • 小增益定理是 H∞H_{\infty}H∞​ 控制的理论基础：设计 KKK 使 ∥M∥∞<1/γ\|M\|_{\infty} < 1/\gamma∥M∥∞​<1/γ，即可保证对 ∥Δ∥∞<γ\|\Delta\|_{\infty} < \gamma∥Δ∥∞​<γ 的鲁棒稳定（直接将鲁棒问题转化为 H∞H_{\infty}H∞​ 优化）。
  • 奈奎斯特判据可推广到鲁棒情形：通过 Nyquist 阵列或 M-Δ 结构的特征值轨迹，判断对不确定 Δ\DeltaΔ 的鲁棒稳定（结构奇异值 μ\muμ 分析本质上是“结构化的奈奎斯特”）。
  • 鲁棒控制将二者统一：对非结构不确定用小增益 + H∞H_{\infty}H∞​；对结构不确定用 μ\muμ（比小增益紧致）；奈奎斯特提供直观频率域解释（增益/相位裕度对应不确定性容忍度）。
  • 小增益是保守的（忽略结构），奈奎斯特是精确的（名义），鲁棒控制（如 μ\muμ）则兼顾精确性与实用性。

总之，小增益定理将奈奎斯特的“点”稳定推广到“集”稳定，是连接经典控制与现代鲁棒控制的桥梁。
